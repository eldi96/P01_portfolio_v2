## 🌐 사이트 바로가기

**[ELDI 포트폴리오 열기 →](https://p01-portfolio-v2.vercel.app/)**

설치나 실행 없이 위 링크로 바로 볼 수 있습니다. PC와 모바일에서 접속할 수 있습니다.

ELDI의 개발자 포트폴리오입니다. 기존 `eldi96/portfolio`와 별도로 관리합니다.

## 로컬 개발용 실행

```sh
npm run dev
```

기본 로컬 주소는 http://127.0.0.1:4173 입니다. 별도 빌드 없이 정적 파일로 배포할 수 있습니다.
Node.js만 있으면 실행할 수 있으며 별도 의존성 설치는 필요하지 않습니다. 브라우저용 Anime.js와 Three.js는 `js/vendor/`의 파일을 사용합니다.
`npm run check`로 JavaScript 문법을 검사합니다.

## 구성

- About: 전체 화면 건축 이미지가 스크롤에 따라 도형 안으로 모이며 소개를 보여줍니다.
- Work: 프로젝트별 모션 그래픽과 실제 작동 사이트 링크를 제공합니다.
- Learning: 같은 입자가 수집·연결·형태 구성으로 이어지는 실시간 WebGL 모션을 사용합니다.
- Principles: 계획·해결·전달이라는 작업 원칙과 경험을 소개합니다.
- Contact: 이메일 및 GitHub 링크를 제공합니다.

어두운 배경과 아이보리·금빛을 사용하며, 모션 감소 설정에 대응합니다.
화면 하단의 모션 설정에서 이 사이트의 효과를 켜거나 끌 수 있습니다. 기본값은 시스템 설정을 따르며, 직접 선택한 설정은 해당 브라우저에 저장됩니다. `시스템 설정 따르기`로 선택을 초기화할 수 있습니다.
건축 이미지와 WebGL 미지원 환경의 학습용 대체 이미지는 AI로 제작했습니다.
프로젝트 모션 그래픽은 기능을 추상화한 표현이며 실제 앱 화면과 다를 수 있습니다.

## 라이선스 안내

로컬에 포함된 Anime.js 및 Three.js의 라이선스는 `js/vendor/`에 있습니다.
로컬 연구 자료, 원본 보존본, 의존성 디렉터리는 저장소에서 제외합니다.
